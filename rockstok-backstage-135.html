Security note

Static-site limitation

This page is hidden by filename and password-gated in the browser. It is useful for admin helpers and casual privacy, but it is not true server-side security.

Event saves use browser storage, so they update this browser automatically. For edits that update every visitor, use a backend, protected hosting, or a form/admin service with server-side login.
